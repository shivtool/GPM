स्टाफ ऐपSTAFF APP

📱 स्टाफ के लिएFor Staff

  1. फोन में Chrome खोलें, एडमिन द्वारा दिया लिंक खोलें, Location (GPS) ON रखें और Allow दबाएँ।Open the link in Chrome, keep Location (GPS) ON and tap Allow.
  2. पहली बार अपना संस्थान चुनें, फिर मोबाइल नंबर और User ID डालें। (User ID एडमिन बताते हैं: संस्थान के पहले 3 अक्षर + क्रम, जैसे shr001)First time: choose your Sansthan, then enter mobile and User ID. (Your admin gives the ID: first 3 letters of the Sansthan + number, e.g. shr001)
  3. पहली लॉगिन पर आपका खाता इसी फोन से जुड़ जाता है। दूसरे फोन से लॉगिन के लिए एडमिन से "Phone reset" कराएँ।On first login your account gets locked to this phone. For a new phone ask the admin for "Phone reset".
  4. बड़ा गोल बटन हरा होते ही Check In दबाएँ। लाल हो तो ऑफिस के और पास जाएँ।When the big round button turns green, tap Check In. If red, move closer to the office.
  5. Check Out Check In के कम से कम 2 घंटे बाद खुलता है (बटन पर समय दिखता है)।Check Out opens at least 2 hours after Check In (the button shows the wait).
  6. शाम 8 बजे तक Check Out न किया तो अपने-आप Out होगा और उस दिन Absent गिना जाएगा।If you do not Check Out by 8 PM, it is closed automatically and that day counts as Absent.
  7. "मेरी report" टैब में महीना बदलकर कैलेंडर, घंटे और % देखें; Print/PDF और CSV भी मिलता है।In "My report" change the month to see calendar, hours and %; Print/PDF and CSV available.

✔ सुझावTips: हमेशा एक ही तरीके (Chrome / होम-स्क्रीन शॉर्टकट) से खोलें, ब्राउज़र का डेटा साफ़ न करें, और खुले में 10–20 सेकंड रुककर GPS सटीक होने दें।Always open it the same way (Chrome / home-screen shortcut), do not clear browser data, and wait 10–20 s outdoors for an accurate GPS.
संस्थान एडमिनSANSTHAN ADMIN

🏫 संस्थान एडमिन के लिएFor Sansthan Admin

आप सिर्फ अपने संस्थान का स्टाफ, अटेंडेंस, छुट्टी और रिपोर्ट संभाल सकते हैं — किसी और संस्थान का कुछ नहीं दिखेगा।You manage only your own organization's staff, attendance, holidays and reports — nothing from other organizations is visible.

  1. सुपर एडमिन से Admin ID और अस्थायी पासवर्ड लें। पहली लॉगिन पर नया पासवर्ड रखना ज़रूरी है (8+ अक्षर, अक्षर और अंक दोनों)।Get your Admin ID and temporary password from the Super Admin. On first login you must set a new password (8+ chars, letters and digits).
📊 Dashboard
आज कौन Present, Leave या Absent है — लाइव।Who is Present, on Leave or Absent today — live.
👥 Staff
नाम + मोबाइल डालें; User ID अपने-आप बनती है। हरे कार्ड से "Message copy" करके स्टाफ को भेजें। Block, Phone reset, Delete यहीं।Enter name + mobile; the User ID is generated automatically. Use "Copy message" on the green card to send it. Block, Phone reset, Delete here.
✅ Attendance
तारीख और स्टाफ चुनें → Full day / CL / ML / Office Work या Clear। कई दिन चुनने पर रविवार-छुट्टी अपने-आप छूटते हैं।Pick date and staff → Full day / CL / ML / Office Work or Clear. For many days, Sundays and holidays are skipped automatically.
🎉 Holiday
अपने संस्थान की छुट्टी जोड़ें/हटाएँ। उस दिन Check In बंद और Absent नहीं गिना जाता।Add/remove your holidays. Check In is disabled that day and it is not counted Absent.
🖨️ Report
Summary, Register (P/A) और Details। Print / PDF (A4 landscape) और CSV।Summary, Register (P/A) and Details. Print / PDF (A4 landscape) and CSV.
🧾 Gatividhi (Log)
किसने, कब, क्या किया — सब दर्ज रहता है।Who did what and when — everything is recorded.
SUPER ADMIN

👑 सुपर एडमिन के लिएFor Super Admin

सब कुछ आपके हाथ में। ऊपर के सूची-बटन से "सभी संस्थान" या कोई एक संस्थान चुनें।You control everything. Use the top selector for "All Sansthan" or a single one.

🏢 Sansthan
नाम, लोकेशन (संस्थान के अंदर खड़े होकर "Meri current location lo"), Radius (30–2000 मी), ID Code (3 अक्षर)। Edit, Band/Chalu, Delete।Name, location (stand inside and tap "Meri current location lo"), radius (30–2000 m), ID Code (3 letters). Edit, Block/Unblock, Delete.
🔑 Admin
संस्थान चुनकर Admin बनाएँ — ID और पासवर्ड सिर्फ एक बार दिखता है, तुरंत भेज दें। Reset, Band, Delete भी यहीं।Create an admin per Sansthan — ID and password are shown only once, send them right away. Reset, Block, Delete too.
🆔 User ID
पुरानी ID (जैसे sdm001) हों तो Staff टैब में पीला बैनर दिखेगा — "Naye format mein badlein" दबाएँ और नई ID स्टाफ को बताएँ।If staff have old IDs (e.g. sdm001) a yellow banner appears in Staff — tap "Naye format mein badlein" and share the new IDs.
🛡️ Settings
अपना ID/पासवर्ड बदलते ही बाकी सभी पुराने लॉगिन बंद हो जाते हैं।When you change your ID/password, all other old logins are closed.
⚠ ध्यानNote: Google Sheet किसी से शेयर न करें। संस्थान का ID Code बनने के बाद बदलता नहीं। जिस संस्थान में staff/attendance हो, उसे delete नहीं, "Band" करें।Never share the Google Sheet. A Sansthan's ID Code cannot change once created. A Sansthan with staff/attendance cannot be deleted — use "Block".

FAQ

🛠️ समस्या-समाधानTroubleshooting

"Location permission band hai" दिखता है"Location permission band hai" is shown

लिंक https:// वाला हो, फाइल से न खोलें। Chrome में पता-पट्टी के आइकन से Location = Allow करें, फोन की Location ON रखें, पेज रिफ्रेश करें।Use the https:// link, not a local file. In Chrome set Location = Allow from the address-bar icon, keep phone Location ON, refresh.

बटन लाल है / "Door hain"Button is red / "Door hain"

स्क्रीन पर दूरी और GPS ± देखें। संस्थान की सेव लोकेशन गलत हो सकती है (आपके एडमिन ठीक करें) या GPS कमज़ोर है — खुले में रुकें।Check the distance and GPS ± on screen. The saved location may be wrong (your admin fixes it) or GPS is weak — wait outdoors.

"Mobile, User ID ya Sansthan galat hai""Mobile, User ID ya Sansthan galat hai"

सही संस्थान चुनें (ID के पहले 3 अक्षर संस्थान के code से मिलने चाहिए), मोबाइल/ID जाँचें। संस्थान बदलना हो तो "badlein" दबाएँ।Choose the right Sansthan (the ID's first 3 letters must match its code) and recheck mobile/ID. Tap "badlein" to change Sansthan.

"Ye account kisi dusre phone se juda hai""Ye account kisi dusre phone se juda hai"

नया फोन/ब्राउज़र है। एडमिन Staff टैब में Phone reset करें, फिर नए फोन से लॉगिन करें।New phone/browser. Admin does Phone reset in Staff, then log in from the new phone.

Check Out नहीं खुल रहाCheck Out will not open

Check In के 2 घंटे पूरे होने तक बटन पर प्रतीक्षा-समय दिखता है। 8 बजे के बाद Out नहीं होता।Until 2 hours pass the button shows the wait time. After 8 PM Out is closed.

Admin लॉगिन "Bahut zyada galat koshish"Admin login says "Bahut zyada galat koshish"

15 मिनट रुकें। सुपर एडमिन तुरंत खोलना चाहे तो Apps Script में resetLocks चलाए। पासवर्ड भूले तो सुपर एडमिन "Password reset" करे; सुपर एडमिन भूले तो emergencyResetSuper।Wait 15 minutes. The Super Admin can run resetLocks in Apps Script to unlock now. Forgotten password: Super Admin uses "Password reset"; if the Super Admin forgets, run emergencyResetSuper.

OWNER SETUP

⚙️ पहली बार सेटअप (मालिक के लिए)First-time setup (for the owner)

  1. Google Sheet → Extensions → Apps Script में Code.gs पेस्ट करें, Save।In Google Sheet → Extensions → Apps Script paste Code.gs, Save.
  2. फ़ंक्शन upgrade (नई शीट पर setup) एक बार Run करें।Run function upgrade (setup on a brand-new sheet) once.
  3. Deploy → Manage deployments → ✏ → New version → Deploy (हर बदलाव के बाद यही, "New deployment" नहीं)।Deploy → Manage deployments → ✏ → New version → Deploy (after every change; never "New deployment").
  4. /exec लिंक खोलकर version: v11 role-based-admins देखें।Open the /exec link and check version: v11 role-based-admins.
  5. index.html, app.html, admin.html, guide.html को GitHub Pages पर डालें; स्टाफ को सिर्फ app.html का लिंक दें।Upload index.html, app.html, admin.html, guide.html to GitHub Pages; give staff only the app.html link.
  6. सुपर एडमिन से लॉगिन → पासवर्ड बदलें → Sansthan बनाएँ → Admin बनाएँ → Staff जोड़ें।Log in as Super Admin → change password → create Sansthan → create Admins → add Staff.
